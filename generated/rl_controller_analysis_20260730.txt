  => 크리틱은 살아 있다 (행동 조건부 Q 변화폭이 상태간 변화폭의 22~92%).
     액터만 상태별 결정론적 점으로 붕괴 -> 어려운 상태에서 ±1 로 스냅 -> 뱅뱅.

기전도 수치로 일관된다:
  log_alpha = -0.6223 -> alpha 0.537 -> 탐험 노이즈 std 0.081
  정책 자체 다양성 std                                    0.025
  target_entropy -1.8 의 등가 가우시안 std                0.098
  합성 std                                                0.084
  => 엔트로피 목표의 91% 를 주입 노이즈가 대신 채우고, 정책 자체 기여는 9%.

이는 dacer_pp/config.py 에 이미 적어둔 퇴행 평형과 같은 기전이다:
  "'포화 정책 + 거대 클립 노이즈'가 GMM 타깃 엔트로피를 충족해 버리는 퇴행 평형"
max_log_alpha=ln(1.5) 캡 덕분에 구 버전(alpha 2.9~3.7)보다 약한 형태로 재발했다.

참고: 조향 부호반전은 4~5회/초로, 정책이 잘 도는 hall/teras 에서도 같은 빈도다.
      폭 1.0~1.5m 코리도에서만 눈에 띄게 보일 뿐이고, 속도가 오르면 같은 진동이
      더 큰 횡변위가 되어 무너진다.
